# StreamSoundCast

StreamSoundCast передаёт звук между двумя Windows-компьютерами в локальной сети. Оба компьютера могут одновременно отправлять звук системы или выбранного приложения и микрофон. У каждого направления собственная громкость и выключатель.

## Запуск

1. Скачайте установщик из [GitHub Releases](https://github.com/daniilsiri/StreamSoundCast/releases/latest) и установите приложение на оба компьютера.
2. Нажмите **Подключить** в верхней панели и выберите второй компьютер. Если он отсутствует в списке, воспользуйтесь кнопкой **Подключить по IP**. Свой IPv4-адрес можно посмотреть в **Настройках → Локальная сеть**.
3. Сравните шестизначный код на обоих экранах и нажмите **Код совпадает** на обоих компьютерах.
4. В разделе **Настройки → Аудио** выберите системный звук или приложение, микрофон и устройства вывода. Наведите указатель на название поля, чтобы увидеть подсказку. Отправка микрофона при первом запуске выключена. Включите её в микшере при необходимости.

Микшер показывает имена аудиоустройств и качество связи. В **Настройках → Оформление** можно выбрать русский, английский, немецкий, испанский или французский язык, тему и один из шести акцентов.

StreamSoundCast проверяет GitHub Releases при запуске. В **Настройках → Обновления** можно повторить проверку и установить найденную версию. Установщик обновления проверяется по цифровой подписи. Для перехода с версий 0.1.x один раз запустите установщик StreamSoundCast. Программа загрузит сохранённые настройки.

Для обнаружения и приёма аудио разрешите StreamSoundCast в брандмауэре Windows для частного профиля. Приложение использует TCP 45800 для управления, UDP 45801 для аудио и UDP 45802 для поиска компьютеров.

Захват выбранного приложения и исключение собственного процесса доступны начиная со сборки Windows 20348. Если исключение процесса недоступно, приложение использует обычный WASAPI loopback и приостанавливает входящее воспроизведение. При захвате системного звука StreamSoundCast подавляет копии входящего аудио, которые возвращают сторонние виртуальные микшеры. Для микрофона используется акустическое эхоподавление Windows на совместимых устройствах.

## Сборка из исходников

Понадобятся Rust stable, Node.js, CMake, Visual Studio Build Tools с инструментами C++ и WebView2. Запускайте команды в корне проекта.

```powershell
npm ci
npm run tauri dev
```

Сборка приложения без упаковки в установщик.

```powershell
npm run tauri build -- --no-bundle
```

## Выпуск обновлений

1. Обновите версии в `package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`.
2. Задайте `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` в окружении локальной сборки. Выполните `npm run tauri build`. Используйте ключ, соответствующий публичному ключу в конфигурации приложения.
3. Выполните `node scripts/release-manifest.mjs <путь-к-установщику.exe>`. Рядом с установщиком и подписью появится `latest.json`.
4. Опубликуйте установщик, его `.sig` и `latest.json` в GitHub Release с тегом `vX.Y.Z`. Отметьте релиз как последний стабильный выпуск.

Кодек, пакеты, буферизацию и сопряжение можно проверить отдельно от интерфейса.

```powershell
cargo test --locked --no-default-features --lib --manifest-path src-tauri/Cargo.toml
```

## Устройство приложения

- `src/` содержит интерфейс React, TypeScript, Zustand и стили микшера.
- `src-tauri/src/audio.rs` открывает WASAPI на рабочих потоках с отдельными COM-контекстами.
- `src-tauri/src/media.rs` управляет независимыми кодировщиками и декодерами Opus. Пакеты идут через UDP, а пропуски маскируются Opus PLC.
- `src-tauri/src/network.rs` отвечает за обнаружение, сопряжение, зашифрованное TCP-управление и переподключение. Ключ повторного подключения хранится в памяти до штатного отключения или выхода.
- `src-tauri/src/protocol.rs` определяет двоичный заголовок, формирование ключей после X25519, аутентификацию и шифрование ChaCha20-Poly1305.

В интерфейсе RTT показывает время сетевого запроса и ответа. Целевые 50–100 мс относятся к сквозному аудиотракту и требуют измерения на двух физических компьютерах. Протокол поддерживает одну активную сессию на компьютер.
